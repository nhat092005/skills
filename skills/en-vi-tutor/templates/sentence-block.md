# Sentence Block Template

Copy this block once per sentence. Fill in the placeholders. Delete the
grammar note line entirely if there is nothing notable to say.

```
### [N]. <short label for this sentence>

🇬🇧 EN: <original English sentence, bold and number each technical term, e.g. **term (1)**>
🇻🇳 VI: <Vietnamese translation, full diacritics, bold and number the matching term in the same spot, e.g. **nghĩa (1)**>

📝 Vocabulary:
| # | Term | Part of speech | Meaning | Another example |
|---|---|---|---|---|
| 1 | <term> | <noun / verb / adjective / phrase> | <Vietnamese meaning, full diacritics> | <one example sentence> |

💡 Grammar note: <only if genuinely notable, otherwise delete this line>
---
```

## Notes on style

Flag icons (EN / VI labels, a small dictionary icon for the vocabulary
table) can be used here to make the blocks easier to scan at a glance. Use
plain numbers (1, 2, 3), not circled numbers or other special symbols.
Vietnamese text must always use full diacritics (dấu) -- never strip tone
marks -- so that a human reader or another AI agent reading this output
later cannot misread the meaning. This template file is meant to be
visually friendly; the rules for when and how to use it live in
references/core-rules.md, and the plain English instructions live in
SKILL.md.
